# Drug–Protein Affinity Prediction

A machine learning project exploring the prediction of drug–protein
binding affinity using molecular and protein representations.

## Overview

Drug–protein interactions play an important role in drug discovery.
This project explores computational approaches for predicting binding
affinity between drug molecules and protein targets.

I worked on developing and evaluating affinity prediction models,
with a particular focus on bilinear modeling approaches and the
integration of drug and protein embeddings.

## My Contribution

This project was originally developed as part of a collaborative team project.

My primary contributions included:

- Developing the drug–protein affinity prediction pipeline
- Experimenting with bilinear interaction models
- Integrating drug and protein feature representations
- Evaluating and refining model performance
- Conducting model experiments and analysis

This repository is a curated version highlighting my individual work
and contributions.

## Approach

The general workflow includes:

1. Generate representations for drugs and proteins
2. Combine drug and protein features
3. Model their interactions using an affinity prediction architecture
4. Train and evaluate the model
5. Compare model performance across experiments
